# 项目树

- `AGENTS.md`：正式开发目录、开发约束和验收要求。
- `.gitignore`：排除依赖目录与发布、隔离验收产物。
- `package.json`：DSH host/client 入口、bundle 元数据和验证命令。
- `cordis.patch.yml`：仅注册本插件的 bundle 项。
- `index.js`：宿主服务、鉴权接口、模型检查及编排工具注册。
- `client.js`：左侧“代理模型”入口、角色选择页面和多代理开关。
- `source/defaults.mjs`：五角色初始映射，开关由存储默认关闭。
- `source/store.mjs`：跨工作区配置、历史版本、会话快照和原子持久化。
- `source/router.mjs`：读取启用目录、校验模型、控制开关和调用会话 workflow。
- `source/http.mjs`：同源认证后的配置读取、保存和模式接口。
- `source/handoff.mjs`：完整报告归档、角色交接筛选、实现门控及阶段运行汇总。
- `source/delegation.mjs`：根据显式范围与独立验证需求判断根处理或委派。
- `scripts/build-workflow.mjs`：生成和校验内联工作流脚本。
- `tests/handoff.test.mjs`、`tests/workflow.test.mjs`：报告完整性、角色筛选、门控、路由及实际脚本契约验证。
- `docs/handoff-routing-plan.md`：本次分层交接与委派实现计划。
- `engine/engine.cjs`：已修复的编排引擎源代码。
- `engine/orchestrate.workflow.js`：内联 workflow 脚本，传入宿主执行。
- `scripts/install.mjs`、`scripts/uninstall.mjs`：仅开发使用的目录链接安装与卸载，保留其他 profile 内容。
- `scripts/verify-package.mjs`：检查打包 tarball 的内容与隔离安装卸载范围。
- `tests/`：存储、路由、HTTP、客户端注册和安装范围测试。
- `tests/host.test.mjs`：宿主依赖隔离、工具参数 schema、调用会话路由及接口清理验证。
- `tests/package.test.mjs`：验证发布包缺失工作流、越界入口的拒绝及完整包语法检查。
- `docs/SESSION.md`：当前完成状态、尚未通过的真实验收及下一步。
- `docs/设计提案.md`：用户批准并优化的插件设计提案。
- `docs/implementation-plan.md`：原实现步骤记录，复选框未同步；以 SESSION.md 当前状态为准。
- `docs/marketplace-release-plan.md`：市场发布准备的既定执行计划。
- `docs/marketplace-release.md`：dsh-market 条目规则、tarball 打包检查及人工验收要求。
- `docs/security-review.md`：发布前安全审查范围、结果、数据传输和报告保留边界。
- `docs/release-notes-1.0.0-rc.1.md`：首个预发布版本功能、安装前提及验收范围。
- `README.md`：使用、安装、开关和模型生效时间说明。
- `LICENSE`、`THIRD-PARTY-LICENSE.txt`：插件及原编排器许可。
