# 1.0.0-rc.1

预发布版本。配合 dsh-our-free-model，按 explorer、researcher、worker、tester、reviewer 五角色分配已启用通道模型，以任务分工利用不同通道可用的免费额度。

## 差异与功能

- free-model 管理通道与模型可用性；本插件管理五角色映射、简单任务委派判断和分阶段工作流。主会话模型保持用户选择。
- 配置跨工作区共享，保存后的新主会话使用新映射，已有会话保留原映射；模式开关控制新编排。
- 完整阶段报告归档，后续角色收到相关摘要及原件索引；实现需要根确认方案，失败、取消或归档错误阻止后续阶段。
- 修复开发卸载的缺失 profile 字段、错误传播、备份权限及失败恢复边界。

## 验证范围

已完成本地测试、工作流脚本同步和打包解包检查。公开源码的固定提交 GitHub 下载、标准 DSH CLI 安装、入口检查与卸载已在独立 profile 实测。

此前真实 explorer 运行已有宿主主/子会话证据；最新多阶段交接、其他角色、模型切换及新旧会话行为仍需已登录 DSH 页面完成验收。预发布不表示这些项目全部通过，也不表示已在插件市场收录。

## 安装与数据边界

使用前启用 dsh-our-free-model 所需通道，并选用提供 workflow 工具的会话预设。免费额度和使用条款来自各供应商；本插件不查询余额、不按余量自动调度、不在额度耗尽时自动换模型。

任务与交接会交给用户选择的模型。完整交接保存在本机插件 handoffs 目录，无自动保留期；敏感内容与目录访问由用户管理。详见 docs/security-review.md。
