# 十八项编排优化：设计、实施与验收

日期：2026-10-17。用户已授权依次处理可靠性 1—9、使用流程 10—15、版本与验收 16—18。既有六角色改动属于本次基线，保留。不得改主会话模型、全局 AGENTS、其他插件、真实角色映射或历史副本。

## 实施设计

采用现有插件内的兼容扩展：独立预检、明确证据失效、可恢复的阶段账本；宿主支持的路由与权限通过实际接口接入。保持显式工具可用，不以新的提示词冒充自动分工或沙箱。不采用仅改提示词的方案；不修改 DSH 宿主源文件。

根保留决策与最终验收。没有根方案时默认先探索并明确返回下一步，不直接派 Worker。新约束与旧约束合并去重，不能静默丢弃任一限制；本轮验收标准优先采用显式新值。实现重跑使测试/审查失效，测试重跑使审查失效；恢复基于受控运行标识、同会话同任务与输入指纹，不根据任意调用者伪造的 passed 跳过写任务。

运行前完成整个计划的参数、根方案、阶段依赖、任务边界、模型可用性预检。路径相对实际调用工作区解析，并检查真实文件/父目录的符号链接别名。完整阶段结果先进入内存账本，再尝试持久化；异常返回 partial/blocked 与原始错误、已执行 runId、报告路径和安全的后续操作。副作用不明时禁止自动重试写阶段。

完整证据保存在磁盘，工具返回一次摘要与源索引。恢复读取归档原件；报告引用不作为指令。通道目录按通道隔离错误，只阻断实际使用的故障通道。配置锁根据 owner 存活与锁身份回收，不偷取活锁。

## 文件职责

- `engine/engine.cjs`：纯计划预检、角色提示、图片引用与执行/结果校验；生成脚本由 build-workflow 更新。
- `source/handoff.mjs`：约束合并、证据失效、阶段账本、部分失败、恢复与摘要。
- `source/router.mjs`：会话映射、通道故障隔离、工作区路径正规化、入口与嵌套校验。
- `source/store.mjs`：仅原子配置保存与可恢复锁，由指定 Luna Worker 修改。
- `index.js`：完整参数 schema、宿主接口接入、构建诊断和工具注册。
- `source/delegation.mjs`：按任务可委派性/工作量而非仅范围数判断；不允许高风险决策下放。
- `client.js`：实际运行版本/模式边界/诊断展示。
- `tests/`：先复现失败，再断言真实逻辑，不将 mock 等同宿主验收。
