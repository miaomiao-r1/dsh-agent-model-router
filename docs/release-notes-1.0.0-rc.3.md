# 1.0.0-rc.3（本地候选）

此文档描述工作区中的本地候选 1.0.0-rc.3。候选未发布、未提交市场收录，也未请求真实模型或修改用户真实 profile 配置；rc.1 Release 附件保持不变。

## 本候选内容

- **角色模型预选范围改为宿主全部可用模型**：目录不再使用插件内置的 provider 白名单，改为读取宿主 `llm.listProviders()` 返回的全部已注册通道，再逐个调用 `llm.listModels(provider)` 合并其当前广告的模型。DSH 自带 DeepSeek 通道、`dsh-our-free-model` 免费通道，以及用户自行配置的 provider 都进入同一目录。
- **六角色自由选择**：explorer、worker、tester、researcher、reviewer、visioner 可分别选择任意通道的任意广告模型；保存时仍按精确 `provider/model` 校验该路由是否在宿主当前目录中。目录中不存在的旧选择保留但标记不可用，不自动替换。
- **目录信息更完整**：目录行携带通道显示名、适配器给出的 `description`，以及 `inputModalities`。模型下拉框用 `description` 作为悬停说明；当适配器明确声明 visioner 所选模型仅文本输入时，页面提示“该模型未声明图片输入能力，识图阶段可能失败”。
- **文案与错误信息同步**：页面、工具描述和拒绝信息不再暗示依赖 `dsh-our-free-model`；目录为空、通道查询失败、模型不在目录中等情况分别给出明确原因。
- **通道级故障隔离保持不变**：单个通道 `listModels` 失败只记录该通道错误，其他通道模型仍可选择；宿主未注册任何通道或整体接口不可用时报告目录不可用。

## 兼容与迁移

- 已有 `~/.dsh/agent-model-router/settings.json` 不做迁移或替换；旧映射继续按会话创建时间生效。若某个旧模型已不在宿主目录中，页面会标记不可用并要求重新选择，编排在启动前拒绝不可用路由。
- `source/defaults.mjs` 的六角色初始映射仍是 free-model 通道的路由，仅在完全没有设置文件时写入；它不再代表“允许范围”。新装且未配置这些通道时，页面会提示全部角色不可用，等待用户从宿主目录中选择。
- 本包不依赖 `dsh-our-free-model`。同时安装该插件时行为不变，只是候选目录会额外包含宿主注册的其余通道。
- 源码更新后必须重新加载插件或重启宿主；仅新建会话不能加载新的宿主端代码或浏览器端页面。

## 验收状态

- 经用户批准在项目目录内以更大权限执行只读验证命令：`npm test` 140/140 通过、零跳过；`npm run check` 通过；`npm run verify:host-contract` 九项宿主结构检查全部通过（`workflowModelRouting=true`，结构核对不请求模型）；`npm run verify:package` 通过，候选 tarball 写入 `artifacts/`，buildId=f2714d28…，工作流哈希仍为 a553fff8…。完整包 SHA256 与打包结果记录在本地会话交接文件（不随包发布）。受限沙箱内直接运行 `npm test` 会因禁止子进程 spawn 出现 5 项环境性失败，与本次改动无关。
- 本轮未请求真实模型：当前 desktop profile 的 `cordis.patch.yml` 中 `dsh-agent-model-router` 为 `disabled: true`，插件没有加载到运行会话，因此无法在真实页面或真实编排中验收。启用并重新加载后才能核对实际目录内容、保存与角色路由。
- 新增回归覆盖：目录覆盖所有已注册通道（而非 free-model 白名单）、通道显示名/描述/输入模态透传、空通道不拖垮目录、空注册表明确报错、保存任意通道模型、编排使用非 free-model 路由、visioner 模态提示只在显式声明时出现。
- 未修改主会话模型、全局 AGENTS、其他插件或用户真实角色映射。

## 限制

- “可用模型”指宿主已注册适配器当前广告的模型；适配器仍可能因凭据、额度、端点或模型下线在请求时失败，目录可选项不是成功率保证。
- 插件不查询余额，不按额度调度，不在模型不可用时自动换模型；visioner 的图片能力提示只依据适配器声明的 `inputModalities`，未声明时视为未知而不是判定为不可用。
- 插件通过调用会话可见的 `workflow` 工具执行编排，因此不会经过宿主原生 subagent 工具的模型选择白名单；实际子会话仍受宿主沙箱、guard 与深度限制约束。
